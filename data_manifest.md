# Data Manifest

This repository provides experiment reproducibility materials rather than a full data release.

## Included data

- `results/paper_tables/`: complete paper-level CSV tables used in the manuscript.
- `results/figure_data/`: compact CSV files used to reproduce the plotted experimental figures.
- `data/processed_samples/`: representative samples from large pairwise/detail files.

## Excluded data

The full pairwise/detail CSV files are not included because several files exceed ordinary GitHub limits and are not necessary for verifying the paper-level tables and figures. These files can be regenerated by the pipeline when the processed candidate-level data are available.

The full commercial raw traces are not included unless redistribution is explicitly permitted by the data provider. If a public release is permitted later, the full processed candidate dataset can be added under `data/processed/`.

## Large files excluded from the original working directory

- `table_tnsm_2_3_multiseed_detail.csv`
- `step4_1b_certificate_inflation_pairwise.csv`
- `step4_1_twin_perturbation_pairwise.csv`
- `step4_2_sla_threshold_shift_pairwise.csv`
- `step3_1_ablation_pairwise.csv`
- runtime and rule-shield detail files larger than 100 MB

Representative samples are provided where available.
